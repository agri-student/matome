# リンク集ポータル

複数のホームページ（行事写真ギャラリー・授業/教材ページ・学科/部活紹介など）へのリンクを
1つのページにまとめる、静的な検索付きポータルサイトです。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ本体。`links.json` を読み込んでカード一覧を描画する |
| `links.json` | リンク情報（外部管理データ）。新しいページを追加するときはここに1件追記するだけでよい |
| `style.css` | 見た目・レイアウト・アニメーション |
| `script.js` | `links.json` の読み込み、カテゴリ分け表示、検索によるリアルタイム絞り込み |

## links.json の書き方

```json
[
  {
    "title": "〇〇祭 写真ギャラリー",
    "url": "https://example.github.io/xxxx/",
    "category": "行事写真",
    "description": "簡単な説明文（任意）",
    "thumbnail": "画像URL（任意）"
  }
]
```

- `category` は `行事写真` / `授業・教材` / `学科・部活紹介` を基本としつつ、
  他の値を入れても自動でセクションが追加されます（未指定の場合は「その他」になります）。
- `description` と `thumbnail` は省略可能です。省略した場合、説明文は表示されず、
  サムネイルは代わりのアイコンが表示されます。
- ページを1つ追加するときは、この配列に要素を1つ追記して保存するだけで反映されます。
  `index.html` や `script.js` を編集する必要はありません。

## ローカルでの確認方法

`index.html` を直接ブラウザで開くと、ブラウザのセキュリティ制限により
`fetch("links.json")` が失敗することがあります。その場合は簡易サーバーを使って確認してください。

```bash
# このディレクトリで実行
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いて確認します。

## GitHub Pages での公開手順

1. このリポジトリを GitHub にプッシュします（`index.html` / `links.json` / `style.css` / `script.js` をリポジトリ直下に配置）。
2. GitHub のリポジトリページで **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** を `Deploy from a branch` に設定します。
4. **Branch** で公開したいブランチ（例: `main`）と、フォルダに `/ (root)` を選択して **Save** をクリックします。
5. しばらく待つと、`https://<ユーザー名またはOrganization名>.github.io/<リポジトリ名>/` でページが公開されます。
6. 以降、新しいページを追加したいときは `links.json` に1項目追記して同じブランチにプッシュするだけで、
   数分後に公開ページへ反映されます。
